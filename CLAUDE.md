# Rules for this repository

- This repo (`Breaking-school-cartoons`) is the ONLY place to write files for the Breaking School cartoon project.
- The cloud environment may also attach `shoumik--breaking--city`. That is a separate game project. **Never create, edit, delete, commit or push anything in `shoumik--breaking--city`.** Do not even run installs or builds inside it. Treat it as read-only and ignore it.
- Every generated file (voices, renders, exports, code, assets, logs) goes inside this repo, under the episode folder (e.g. `ep1/`).
- Push review files and finished videos to the `ep1-output` branch of this repo only.
