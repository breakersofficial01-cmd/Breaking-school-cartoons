# Breaking School Cartoons

2D cartoon comedy shorts for Breaking School, built in code with Claude Code.

## Episode 1
Start a Claude Code session on this repo and say:

> Read ep1/CLAUDE_CODE_PROMPT.md and follow it step by step. Start now.

- `ep1/brand/` — put `logo.png` here (optional; a placeholder is used if missing)
- `ep1/music/` — put `bgm.mp3` here (optional)
- `ep1/voices/` — leave empty to generate voices with Gemini TTS
- Finished videos are pushed to the `ep1-output` branch in `ep1/out/`
